# MAGE-A1

Example mRNA encoding the human tumor antigen MAGE-A1, based on SEQ ID NO. 3
from [US20080171711A1](https://patents.google.com/patent/US20080171711A1/en).

`sequence.fasta` contains the published RNA. `input.fasta` supplies its UTRs,
CDS body and poly(A); `experiment.yaml` inserts the original AUG and UGA codons
and runs the bundled CPU sequence-metrics scorer.
